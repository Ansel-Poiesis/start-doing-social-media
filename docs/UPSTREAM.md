# 历史资料与公开项目边界

本项目来自持续维护的内容市场判断研究。部分历史映射使用 Poiesis registry、B 组卡片编号及外部实验台账；这些名称用于说明来源关系，不是运行依赖。

公开仓库包含文章、已有来源定位记录、逐卡映射和工作协议。历史原始登记簿、私人创作样本、实验引擎与发布台账没有随仓库分发，因此未见于公开仓库的原始材料不能被称为读者可复现证据。

`docs/card-registry-mapping.md` 记录 2026-09-26 的 128 条历史登记与六篇卡库文章的关系：79 条映射、49 条不在六篇范围。它不是当前 49 篇阅读文章的覆盖率，也不证明卡片主张正确。

`docs/g02-source-inventory.md` 的 95 张卡是本轮来源追踪的既定集合。已有书目、URL 或出处不等于已经阅读全文或验证主张；具体进度看各条复核说明及维护任务。公开来源、正文与后续结构化登记的可复现性仍是开发事项。

公开版本维护自己的可运行代码、skills 和证据；不要求读者访问任何私人目录，也不自动迁移或运行历史引擎。
