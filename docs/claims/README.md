# 主张登记与更正传播

本目录登记高风险平台规则、平台数字与会影响决策的方法边界。登记状态描述证据与维护状态，不代表平台背书。平台条件变化快，使用前仍需核对当期官方页面和具体账号。

registry.json 是主张与消费者的结构化索引。每条记录包含唯一 ID、旧主张或裁决、范围、复核日期、来源状态，以及正文段落、卡片、配套协议和 skill 的消费者。文章对象及 Markdown 前置元数据重复声明 claim ID，npm run check 会校验消费者存在、标记齐全、锚点有效；移除消费者标记会使检查失败。

来源状态与主张裁决分开填写。找不到原文时明确写 not_located，并保留内部勘误凭据；单个创作者、二手转载或媒体报道不能升级为平台通则。verified_as_of_review 只表示所列来源在所列日期支持限定范围内的主张。

本批覆盖 2026-09-27 首发级修订中优先级最高的规则与数值；它是可执行的第一批登记，不宣称已经穷尽全库。全量来源定位、账号资格及其余待核规则继续由现有 Player Todo 任务推进。完整传播示例见 audit/2026-09-27-claim-propagation.md。
