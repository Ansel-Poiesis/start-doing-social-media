# 0.11.0 首个公开维护版本

发布目标：`Ansel-Poiesis/start-doing-social-media`，版本 `v0.11.0`。本文件记录版本范围；远端 tag 的 commit 与 GitHub Actions 记录是发布状态的可查询证据。

## 内容

49 篇文章、49 个配套 article_id、六个技能和六份模板。逐篇基线、具体改进与剩余风险见 [审计](../audit/README.md)；旧待办承接与新开发任务见 [TODO](../../TODO.md)。

## 验证范围

- 阅读器结构：49 篇、六主题、二十问、链接与模块依赖。
- HTTP：74 个请求覆盖公共文件、GET/HEAD、MIME、方法限制、私有文件隔离、路径和畸形 URL。
- 浏览器：49 个正常文章路由、跳转正文、首页与未知路由目录清理，见 [工程记录](../audit/2026-09-27-engineering.md)。
- Skills：全文导出保留状态和来源、模板与依赖、合成场景交接；见 [技能验证](../audit/2026-09-27-skills-validation.md)。
- 公开边界：Git 跟踪/暂存内容扫描，私人配置、运行历史、旧引擎及参考截图不纳入；扫描器使用隔离测试验证常见误漏报。
- CI：Linux 与 Windows 的 Node.js 24 检查。实际通过结果以本版本 commit 的 Actions 记录为准，不能由工作流文件存在推定。

## 使用限制

本版是开放研究和维护起点。关键主张已定向勘误，尚未完成每篇改后重新评分或每条来源全部复核。G02 的 95 张卡有未定位/未核实项，真实创作者及作品全链路没有完成验证。网站没有部署到公开域名，六个 skill 不执行账号登录、付费调用或发布。

## 复现

克隆仓库并切换 tag `v0.11.0` 后，运行 `npm run check` 与 `npm run check:release`；阅读器用 `npm start` 启动。依赖仅为 Node.js 和 Git，不要求私人目录、账户或已运行服务。
