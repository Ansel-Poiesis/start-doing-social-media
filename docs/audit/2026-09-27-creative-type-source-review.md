# TASK-10.22 创作模式依据复核

复核日期：2026-09-27
范围：creative-type 正文中的 VCTI 转述、视频研究引用、创作模式论断，以及小规模试答的证据边界。本文记录来源与观察；它不表示参与者验证已经开展。

## 结论

- 正文已把项目的原创五维创作模式放到主线，外部 VCTI 仅留作有来源的观众视角参照；删除未经来源支持的“某类型天然更有传播优势”等断言。
- 2018 年“18 项、娱乐价值排名第一”的数据可对应 Törhönen、Sjöblom 与 Hamari 的 GamiFIN 论文。它报告 2017 年收集的 385 份社交视频创作者问卷，不是“Aalto 2019、375 位创作者”。娱乐价值的感知重要性均值为 5.65/7。该测量是创作者对受欢迎因素的主观估计及自报投入，不是实际效果或因果检验。
- 2019 年的 377 位创作者研究是另一篇创作动机研究，比较内在与外在动机，不是 18 项受欢迎因素排名。
- 2023 年言语行为论文确实报告指令性言语与播放、评论、点赞的相关，但样本只含 8 位美妆 YouTuber 的 12 条赞助视频，且视频均超过百万观看；不能推出普遍策略、因果关系或销售效果。本轮无法逐句确认视频是否引用的就是这篇论文。
- 2020 年幽默传播论文没有定位到唯一原文，也无法建立视频引用与某一候选研究的确定对应，暂不在正文使用。
- 本项目没有真实创作者试答资料，也没有建立或验证任何分类。3–5 人的探索式记录方案为空白模板，不能支持人格、信效度、预测或传播效果结论。
