# 指标、假设与经验卡逐条复核

日期：2026-09-27。对应 Player Todo：TASK-10.17。此报告记录假设、门禁与卡片的编辑裁决和来源缺口；“已复核”不等于“已验证有效”。

## 复核范围与判读

逐行阅读全文与验证方式：98 条假设（M 31、C 14、T 16、E 21、L 16）、`gates` 文3层门禁/5节、六篇卡库79条（跨平台3、平台18、学术16、标杆6+创作者方法7、变现15、形态方法14）。行级 ID 均保留。T14 是场景核验流程，T15 是限定到具体首发计划的规则引用；两者不是待验证的传播效果假设。L 层也含统计范围、治理约定和效果假设，不能把整层当作一种证据类型。

表中“保留/限域”只说明措辞可作为条件明确的观察问题；“撤回/重写”表示不再作为通用机制或门槛；“流程/规则”属于治理或适用规则，不通过账号流量试验确立；“待源”表示原始来源定位不足。反例/未知写在各 ID 行，后续补证必须能回到对应 ID。相同作者重复发布、论文之间编辑类比、拆卡复述都不构成独立互证。

## 门禁：3层、5节

| 部分 | 裁决 | 反例、边界与待核 |
| --- | --- | --- |
| `vocab` | A/B/C 仅作内部交接状态；不是预测评分。明确法规、规则、权利与授权限制要解决后才能继续。 | 普通编辑顾虑不自动等同违法风险；不确定处先查证，不以“风险分”取代条文。 |
| `column` | 需求、供给、交付与风险是可裁剪的问题框架；不预测栏目成功。 | 热度弱不等于无需求；可列题目多不等于能交付；成本与读者价值可能冲突。 |
| `probe` | 先写问题、观测与资源边界；多因素试作只作探索，样本数量和日期不自动转正。 | 同时变化选题、形式、发布时间时无法分辨作用；未观测到也可能是字段不可得。 |
| `topic` | 五问用于检查读者问题、证据、增量、形态和风险；目标可并列，指标不和点赞/收藏/评论机械绑定。 | 审美作品可以不追互动，清单也可能引发讨论；信号之间会冲突且有些目标难量化。 |
| `expression` | 标题、核心句、首图检查用于编辑审读；不设20字、固定候选数、每图三层或互动效果门槛。 | 设备、入口、作品承诺和读者熟悉度不同；表达清楚不保证点击或分发。 |

## 假设逐条裁决

### M 层（31条）

| ID | 复核结论、反例或未知 |
| --- | --- |
| M1 | 撤回“首30分钟至数小时互动决定流量池”；早期观察或能预测后续，但因果与统一窗口未知，题材/入口也可解释差异。 |
| M2 | 保留按分布与决策目的选统计量；抽样代表性、极值处理和分位数算法仍需报告。 |
| M3 | 保留评论关系作为条件性假设；评论也可能是题材、受众或曝光的结果，不能当因果。 |
| M4 | 撤回“当天衰减、搜索决定寿命”；信息流与搜索来源可能并存，按平台可见入口逐窗记录。 |
| M5 | 撤回赞/藏/评/转与单一心理意图的一一映射；同一行为可有多种动机，互动不穷尽创作者目标。 |
| M6 | 限为承诺错位可能产生理解落差；信任、收藏或负面反馈也受题材与受众影响，避免“惩罚律”因果措辞。 |
| M7 | 撤回元数据“决定”初始精准度；标签权重未知，标题、正文、资格和受众入口都可能影响观察。 |
| M8 | 回复与后续结果保持待检；自然回复受问题类型和作者投入影响，不应为试验故意不回复。 |
| M9 | 撤回搜索词强度决定曝光上限；搜索排名和推荐曝光是不同入口，堆词也可能损害阅读。 |
| M10 | 限于具体论文中的新内容策略；对某账号、平台现行冷启动是否适用未知。 |
| M11 | 限于 Monolith 论文描述的反馈训练系统；不证明目标平台有同样时延或首小时优势。 |
| M12 | 保留低分母下比例不确定性可能较大；须明确单位、分母、成功定义和依赖结构，重复事件不能直接视作独立试验。 |
| M13 | 保留预测力因平台、题材和窗口不同；还须有留出验证，训练样本相关性不代表外推效果。 |
| M14 | 撤回“累积优势+随机决定名次”；发布前事实、权利与制作检查是流程，不能预测排名。 |
| M15 | 保留逐平台检验互动关联；互动名称与定义不同，不能合并“深浅权重”。 |
| M16 | 限于历史社会影响实验所处任务；实验干预结果不能直接迁移到短视频账号。 |
| M17 | 撤回全平台加权公式和“高CTR标题党系统性衰减”；公开目标说明不等于具体权重或排序因果。 |
| M18 | 保留微信社交传播为待检问题；公众号/视频号、在看/推荐入口和关系链不合并为单一闸门。 |
| M19 | 旧流量池数不能作基准，也不能单独证明普遍赛马结构；精确来源和年代按卡记录。 |
| M20 | 撤回跨平台粉丝溢价共性；收益、阅读与资格分别受计划、受众、内容和来源影响。 |
| M21 | 官方扶持/征文公告只支持计划条件；参与不保证自然分发加成或收入。 |
| M22 | B站各类互动与推荐权重保持待检；0.3法则未获当前官方确认，观看、投币、分享不是同一结果。 |
| M23 | 撤回分钟级模型反馈与新笔记效率+50%；未找到可复核当前来源，相关性也不能证明系统时延。 |
| M24 | 限于小红书具体论文任务；内容表示的作用不能推出粉丝、账号或其他信号不起作用。 |
| M25 | 搜索意图可能超过字面匹配是候选机制；搜索行为是否进入推荐画像未证，须区分搜索与推荐来源。 |
| M26 | 隐藏/不感兴趣是否入模、如何使用及权重均待平台来源；不可见反馈记不可得，不能由低流量倒推。 |
| M27 | 用户侧多样性重排不推出创作者固定间隔；发布节奏还混有题材、账号和时机因素。 |
| M28 | 报备与自然内容的差异可能由作者、品类、预算和商业义务解释；不承诺固定加成。 |
| M29 | 撤回跨平台搜索行为反哺推荐画像和“SEO双收益”；同名机制不等于同一系统或独立证据。 |
| M30 | 保留硬币等行为作为定义清楚的反馈计数；稀缺不代表算法权重、真粉浓度或价值。 |
| M31 | 撤回粉丝“收益系数+冷启动种子+低质兜底”三合一说法；后台未必有分群字段，规则需分平台核。 |

## 统一指标口径与合成示例

目标由创作者选定，可并列包括学习/理解、审美体验、表达、互动关系、转化或其他。先说明这轮需要判断什么，再为每个目标选可得信号；只有决策确需比较时才指定优先目标，并写下其他目标及不可接受代价。平台互动率不自动代表作品总价值。

- **计数：**观察到多少个明确单位。例：`5名读者准确复述`；计数本身无需分母，但应记录受测者定义、去重和抽样来源。
- **比率：**`符合事件定义的分子 / 合格分母`。例：完成指定试读任务的8人中5人准确复述，即5/8=62.5%；须写明任务、分母资格与窗口。重复评论数/曝光不是自动成立的二项比例。
- **分位数：**对有序观测值报告位置；须说明比较单位、筛选条件和算法。例：审美评分排序为`[1, 2, 2, 3, 4, 4, 5, 5]`，采用Type 7经验分位数时P75=4.25。它是小样本的描述，不是成功线，也不是Wilson比例区间。
- **区间：**说明参数、抽样/分配设计、估计方法和假设。合成演示将两个独立组各随机分配8名试读者，A组4/8、B组3/8能准确复述。各组单独计算的95% Wilson区间约为21.5%–78.5%和13.7%–69.4%。样本很小，区间宽；这只演示如何报告，既不能据此说A更好，也不能通过比较区间是否重叠来代替正式差异估计。
- **缺失状态：**记录实际观测到的零、未收集、未显示、不可得、不适用和受抑制。后台没有提供留存字段是“不可得”，不是零；字段存在、完整观察窗内确实未发生事件才记0。平台展示但分母不可见的比率按原名/口径留存，不自行造分母。
- **可比性：**平台、入口、作品形式、样本资格、发布时间窗、指标定义或目标不同时先分层。区间不会修复选择偏差/依赖，也不会证明因果或实务意义；探索性小样本仍能发现理解障碍，但不能冒充总体效果估计。

## 依据与未决边界

- [NIST：比例置信区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)：说明Wilson方法适用于比例区间，也列出小计数场景的二项方法；不用于排序分位数。
- [NIST：Percentiles](https://itl.nist.gov/div898/handbook/prc/section2/prc262.htm)：说明经验分位数基于顺序统计量，并介绍多个插值法；不同软件可能给出不同值，须记录算法。
- [NIST：区间估计](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35.htm)：区间表达参数估计不确定性；统计与实务意义、模型假设需分别判断。
- [UN Statistics Division：Household Sample Surveys，第82段](https://unstats.un.org/unsd/publication/seriesf/seriesf_98e.pdf)：区分正确值未知的缺失与实际零值。此处仅引用数据定义，不把该手册的调查估算方案移到创作者数据。

本仓库尚无经授权的真实贯穿作品/平台后台数据；本例明确为合成教学。计量协议有外部方法依据，但指标与内容目标的映射是可调整的项目设计，尚未用真实创作者试用验证。账号资格、后台字段和平台效果继续保持未知，不能以结构检查通过替代内容有效性。
