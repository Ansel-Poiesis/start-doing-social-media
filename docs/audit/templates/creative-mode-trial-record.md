# 创作模式探索式试答记录（空白模板）

## 使用边界

这是空白的可复查记录格式，不是心理测验、临床工具、正式效度研究或招募通知。只有在负责人另行决定开展并取得参与者明确同意后才填写。每次试答仅能帮助发现问题措辞歧义、条件差异、反例及具体决策是否改变；3–5 人不能证明类型稳定性、预测效度或创作效果。

不得把含有姓名、账号、联系方式、私信、未公开作品或其他可识别资料的原始回答放进公开仓库。若将来需要保存原始材料，先确定参与者同意范围、保管人、访问权限和删除时间，并保存在合适的非公开位置。没有明确同意就不录音、不截图、不留原话。

## 反例检查

对每一条候选描述都问：

1. 最近一次它不成立的情境是什么？
2. 是否有看起来相同、但因为受众、平台、资源、职业阶段或作品形式不同而产生相反选择的情境？
3. 这条描述能否被作品或具体经历检查？如果只能靠“像某种人”来解释，标为不可核实。
4. 参与者是否不同意描述，或认为它不改变行动？原样记下分歧，不说服对方接受类别。
5. 若暂时不采纳该描述，下一项制作选择会有什么不同？

### 允许写出的结论

- “这道题有两种理解，需改写。”
- “这位参与者认为某项记录帮助他/她比较了两个制作选择。”
- “该描述在给定经历中不适用，出现了反例。”
- “目前样本和证据不足，不能判断。”

### 不得写出的结论

- “该类型已被验证”或“该类型适用于某类创作者”。
- “五维能预测账号成功、流量、收入或持续创作。”
- “多数创作者都如此”，除非有匹配的抽样与研究设计支持。
- 用 3–5 位便利参与者生成普遍规范、量表分数或确定类型。
