# 跨平台版本适配：Agent 参考流程

修订日期：2026-09-27。对应正文：持续运营与合作 / 一份内容如何适配多个平台。目标是管理内容版本、来源和权利，不提供分发策略或流量预测。

## 触发条件与输入

当创作者考虑把同一选题或母稿改为多个平台/入口的版本时使用。输入包括：

- 母稿及版本号、主要观看承诺、目标观众处境、必须保留的事实和限定。
- 视频、音频、图片、字体、引用、肖像、商标等素材的来源与许可。
- 目标平台、具体入口、地区、账号、发布日期窗口及协作者。
- 创作者选择的各版本用途：自然发布、品牌转发、付费投放、内部预览等。

来源不清的素材先标为待确认，不因网络可下载或平台上可见而默认可复用。

## 操作步骤

1. 创建母稿记录，保留只读基线；为每个渠道版本建立独立 ID 和父版本关系。
2. 为目标平台各填一行版本矩阵，写清观众任务、标题/封面/开头、内容顺序、字幕、行动入口和改动理由。
3. 对每项素材检查权利人、取得方式、署名要求、平台、地区、期限、商业使用、广告投放和再授权范围。涉及授权时保存许可文件或确认记录。
4. 核验该平台当前的格式说明、原创或重复内容规则、广告/AI 标识、音乐使用及链接限制。保存官方原文 URL、页面日期、查阅日期、适用入口和账号可见状态。
5. 对照母稿复核事实、引用、必要限定和承诺；剪辑不得改变含义或制造证据不支持的体验。
6. 按平台分别审批、记录操作者与发布回执；逐平台保存数据和统计口径，不合并成“总流量”或用于平台排名。

## 例外

- 权利或许可不清：停在草稿，替换素材或取得适用许可。
- 合作方授权没有说清是否覆盖付费广告、改编、期限、地区和渠道：不开放相应使用。
- 官方规则不可访问或当前账号资格未知：登记未知并暂停受影响的公开版本，不拿旧文章补成当前规则。
- 同一内容存在不同事实或必要限定：不能机械复制；重新编辑或取消版本。
- 仅适配标题和比例、没有重新核对事实与权利：不得标为已审核。

## 来源与限制

- 本站平台文章、平台长文写作契约、制作单与规则差异表提供阅读入口；其中待核项仍然是待核项。
- YouTube 提供[从自己已上传的视频制作 Shorts](https://support.google.com/youtube/answer/12836917?hl=en)及[内容商业化权利说明](https://support.google.com/youtube/answer/2490020?hl=en)，只说明该平台当前工具/政策示例，不能作为其它平台或其它许可的证明。
- 没有证据支持跨发一定增加触达、节省成本或受到某个算法奖励。本方法仅是版本管理与发布前核验流程，尚无本站真实运营效果验证。
