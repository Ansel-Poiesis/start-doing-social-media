# 商业合作与项目核算：Agent 参考流程

修订日期：2026-09-27。对应正文：持续运营与合作 / 商业合作：先核范围，再谈交付。本协议不是法律、税务、会计或行业报价意见；不要求创作者商业化。

## 入口判断

只有创作者本人把收入列为目标、主动收到合作邀约或准备出售服务/授权时才启动。先确认创作者可以拒绝、暂停或把合作范围缩小。非商业目标标记为“不适用”，而非“尚未完成”。

## 输入与筛查

先收集品牌/代理主体及联系人、产品/服务、目标市场和平台、内容目的、受众、交付、期望行动、报酬形式、期限、使用成品的权利、审核流程及数据要求。

核对主体授权、产品材料和主张支持、样品/素材来源、创作者是否能够诚实表达、可能利益冲突和目标平台现行政策。出现下列情况时暂停或拒绝：

- 对方无法证明其有权委托，或要求绕过平台、法律或必要披露；
- 要求创作者伪造购买、使用体验、数据或未能证明的效果；
- 不愿限定素材使用渠道、地域、期限、广告投放/再授权或报酬；
- 要求账号密码、个人敏感信息或未成年人资料，而项目不能证明必要性；
- 特殊受监管类别的具体要求超出项目组核验能力。

## 项目记录流程

1. 保存合作简报版本、双方确认范围、联系人、报价有效期和不包括的事项。
2. 将交付件、技术格式、初稿/终稿时间、验收标准、审核人、修订轮次、补拍、延迟、取消和付款节点逐项写明。
3. 分别登记自然发布、品牌转发、付费广告、账号授权广告、剪辑再利用、其它平台/渠道、地域、期限、独家限制与到期下架。不要把平台授权按钮当成完整合同范围。
4. 核验宣传主张、素材权利、产品资质以及各目标地区和平台的广告/商业披露。保存适用原文、日期、渠道、账号状态和实际披露凭据；法律适用不清时转交合格专业人士。
5. 逐项提交并记录文件版本、时间、收件方、验收状态、客户反馈与变更。对产品主张或素材有实质变更时重新审查。
6. 分栏保存报价、已确认金额、应收/已收、佣金、退款、平台费用、税费、外部成本和工时。币种、日期、凭据及缺失状态不可省略。未经实际确认和凭据支持的金额不写为收入。

## 报价边界

项目报价只服务于当前范围：将预计制作与沟通工时、硬成本、复杂度、风险责任、修改轮次、期限/地域/平台/媒介授权、独家限制及税费/收款成本列成可谈项目。区分估算、提出价、双方确认金额和实际收入。不提供跨账号通用收费表、收入倍数、平台费率或成功预测。

## 来源与法律边界

- 中国大陆适用事项参考全国人大公布的[《中华人民共和国广告法》](https://www.npc.gov.cn/npc/c1773/c1848/c21114/c25274/c25277/201905/t20190521_207459.html)、市场监管总局发布的[《互联网广告管理办法》](https://www.samr.gov.cn/cms_files/filemanager/1647978232/attach/20234/W020230320579023662253.pdf?fileName=W020230320579023662253.pdf)及[《互联网广告可识别性执法指南》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/ggjgs/art/2024/art_89824524f2804c5594e95408fbdf8602.html)。文件有各自定义、主体、条文与地域范围，不能代替具体法律判断。
- YouTube 的[品牌内容披露帮助页](https://support.google.com/youtube/answer/154235)及 TikTok 的[商业内容披露帮助页](https://support.tiktok.com/en/business-and-creator/creator-and-business-accounts/promoting-a-brand-product-or-service)是各自产品政策实例；资格、按钮和执行规则须在具体账号、地区和时间重查。
- 对特殊品类、广告认定、合同责任、个税/增值税、跨境收款、肖像和素材权利等问题不作专业判断；按具体合作寻求专业法律、税务或权利人确认。
