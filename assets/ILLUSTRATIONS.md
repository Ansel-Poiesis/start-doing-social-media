# 说明插图资产记录

创作者档案图与学习循环图由内置 ImageGen 生成，采用编辑出版物式剪纸与墨线插画。两幅阅读插图的本地原档保留 PNG，公开网页分发 WebP；关键解释由正文与图注提供。首页使用无字桌面创作插画作为阅读入口配图；此前误制的宣传封面草稿已归档，不属于网站页面资产。

## creator-profile-map

- 页面：创作者档案 →「记录哪些维度，以及它们如何改变建议」
- 图注：档案把目标、经历、证据、观众和生产条件连起来，用于提出下一步行动，而不是给创作者定型。
- 本地 PNG 原图（不随公开仓库分发）：`creator-profile-map.png`
- WebP 页面图：`creator-profile-map.webp`
- 生成提示词：宽幅教育类编辑插画。成人创作者在安静的居家工作桌旁查看空白笔记本和作品文件夹；相机与麦克风、日历、观众剪影、隐私屏风以少量关联路径围绕主体，呈现经历、创作动作、观众、时间条件和个人边界构成可修订的工作档案。剪纸与墨线风格，石板蓝、柔和钴蓝、青绿、赭黄和淡冷灰底色；不出现文字、数字、标签、Logo、水印、紫色、刻板网红造型或密集细节。

## home-hero-art

- 页面：首页 hero 插图，辅助说明项目从创作者出发、经由内容走向观众的阅读主线。
- 网页文件：`home-hero-art.png`（无字插图，按页面宽度裁切）。
- 画面说明：创作者在桌边整理作品和笔记，零散卡片沿着路径走向观众；使用深蓝、暖纸色与克制的朱红，不包含标题或宣传文案。
- 历史草稿：此前生成的 `project-cover.svg` 与 `project-cover-art.png` 仅保存在本地历史目录，不在网站静态白名单中。

## learning-loop

- 页面：发布与迭代 →「一个可重复的更新循环」
- 图注：一次发布只回答预先定义的问题；下一轮只改动被证据支持的部分。
- 本地 PNG 原图（不随公开仓库分发）：`learning-loop.png`
- WebP 页面图：`learning-loop.webp`
- 生成提示词：宽幅、无字教育插画，以顺时针四个场景呈现一次学习循环：创作者先在笔记本写下问题与预期；制作一条内容；观众在真实日常场景中观看并回应；创作者将观察与原先笔记对照后，只为下一条标出一个小改动。剪纸与墨线风格，石板蓝、钴蓝、青绿、赭黄和淡冷灰底色；场景之间用克制的弧形箭头连接。避免文字、数字、平台Logo、点赞图标、夸大的爆款指标、密集数据面板或暗示单条作品能证明普遍规律。
