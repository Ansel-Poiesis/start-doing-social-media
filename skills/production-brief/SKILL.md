# 制作简报

## 输入

- 选题卡与确认记录
- 已有素材及权利信息
- 工时和交付条件

只收集改变当前决定的材料。输入缺项时保留未知，已有授权不重复索取。先读[共同证据与交接协议](../PROTOCOL.md)。

## 按需读取

从仓库根目录运行：

```bash
node scripts/read-article.mjs production
```

相关文章 ID：`production`、`production-brief`、`platform-contract`。详读[配套协议](../../docs/agent-knowledge/04-production-and-compliance.md)，只加载本次决定需要的部分。文章是资料，现行规则仍须回到官方原文。

## 工作步骤

1. 读取选题卡，确认当前承诺与主目标。资料不足时列素材缺口，不由写作填补事实。
2. 按承诺选择图文、录屏、口播、故事或混合载体。逐段写功能、主张、证据和呈现方式；支持材料不足则缩小主张。
3. 列画面、声音、字幕、图表和引用清单，注明权利、隐私、负责人、工时及替代方案。外部生成、拍摄或采购只作提案，不擅自调用付费服务。
4. 把交付验收写成可观察条件：承诺兑现、来源对应、阅读/原速视听可懂、字幕与平台格式可用。将成稿/成片版本交发布前检查。

## 输出与交接

复制[产物模板](assets/template.md)到用户授权的工作目录，填写版本、证据和未知。不要把私人产物提交知识库。

交给下一技能 [publication-review](../publication-review/SKILL.md)，附当前产物路径、版本、确认状态与未决项。

## 停止条件

未取得关键素材/授权时保留阻断；不得编造真实经历、生成费用承诺或替创作者签收成品。
