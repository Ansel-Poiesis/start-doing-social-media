# 创作者档案

## 输入

- 创作者自述或已确认档案
- 可公开作品与反馈（可缺）

只收集改变当前决定的材料。输入缺项时保留未知，已有授权不重复索取。先读[共同证据与交接协议](../PROTOCOL.md)。

## 按需读取

从仓库根目录运行：

```bash
node scripts/read-article.mjs profile
```

相关文章 ID：`profile`、`creative-type`。详读[配套协议](../../docs/agent-knowledge/01-profile.md)，只加载本次决定需要的部分。方向搭配见 `platform-research` skill；文章是资料，现行规则仍须回到官方原文。

## 工作步骤

1. 先读题库与档案文章，只问会改变当前建议的缺项。保留原话，允许跳过；本轮不想访谈时直接回答其问题。
2. 按目标、供给证据、表达动作、观众场景、产能边界五组整理。自述 M、观察 O、事实 F、推断 I、假设 H、意愿 D 分栏，不把未知写成没有能力。
3. 每条方向建议指向具体档案字段；列反例、代价与最小试作。分类词只作为待确认描述，不生成成功概率或人格诊断。
4. 交付档案草案与最多三个关键未知，逐项记录本人确认/未确认。下一步只使用与当前决定有关的字段。

## 输出与交接

复制[产物模板](assets/template.md)到用户授权的工作目录，填写版本、证据和未知。不要把私人产物提交知识库。

交给下一技能 [platform-research](../platform-research/SKILL.md)，附当前产物路径、版本、确认状态与未决项。

## 停止条件

缺少本人参与时，只给问题表或整理明确提供的材料；不得合成真实回答。方向、长期人设与敏感经历需本人确认。
